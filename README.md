# QuickNotes

A fast, lightweight, and responsive web application designed for capturing everyday thoughts, ideas, and tasks with zero distraction.

## Features

- **Categorized Notes**: Organize notes by Personal, Work, or Study with color-coded side borders.
- **Input Validation**: Enforces note limits (1 to 200 characters) with real-time error messaging.
- **Instant Search**: Filter through notes in real time without reloading the page.
- **Persistent Storage**: Automatically saves all notes to browser `localStorage` so notes survive page reloads.
- **Responsive Card Layout**: Seamless mobile-to-desktop design with vertical stacking for small screens (<600px).
- **Clear All Confirmation**: Optional one-click wipe that prompts for confirmation before clearing the workspace.
